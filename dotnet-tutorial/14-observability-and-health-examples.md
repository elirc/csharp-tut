# 14 - Observability and Health Examples

| # | Example | Explanation |
|---|---|---|
| 1 | `AddHealthChecks()` | Registers health checks. |
| 2 | `MapHealthChecks("/health")` | Exposes health endpoint. |
| 3 | `liveness` | Is the process alive? |
| 4 | `readiness` | Can the app receive traffic? |
| 5 | `structured logs` | Queryable log fields. |
| 6 | `correlation id` | Connects work across components. |
| 7 | `trace id` | Identifies a distributed trace. |
| 8 | `Activity.Current` | Current .NET tracing activity. |
| 9 | `OpenTelemetry` | Standard observability instrumentation. |
| 10 | `metrics` | Numeric measurements over time. |
| 11 | `counter` | Metric that increases. |
| 12 | `histogram` | Metric distribution such as latency. |
| 13 | `request duration` | Key web service metric. |
| 14 | `error rate` | Failed requests over total requests. |
| 15 | `dependency latency` | Time spent calling external systems. |
| 16 | `Application Insights` | Azure observability tool. |
| 17 | `Prometheus` | Metrics scraping system. |
| 18 | `Grafana` | Visualization/dashboard tool. |
| 19 | `alert` | Notification from important signal. |
| 20 | `dashboard` | Shared operational view. |
