# 04 - App Models

.NET supports several application models. The app model determines templates, project SDK, hosting model, dependencies, and deployment shape.

Common app models:

- Console apps for scripts and command-line tools.
- Class libraries for reusable code.
- Worker services for background processes.
- ASP.NET Core Web APIs for HTTP services.
- Razor Pages and MVC for server-rendered web apps.
- Blazor for interactive web UI with .NET.
- Desktop apps with WPF or Windows Forms.
- Cloud-native apps with containers and orchestration.

Start with the simplest app model that fits the problem. Do not make every project a web API if a console tool or worker service would be clearer.
