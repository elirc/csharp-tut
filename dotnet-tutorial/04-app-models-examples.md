# 04 - App Models Examples

| # | Example | Explanation |
|---|---|---|
| 1 | `dotnet new console` | Command-line or simple app. |
| 2 | `dotnet new classlib` | Reusable library. |
| 3 | `dotnet new worker` | Background service app. |
| 4 | `dotnet new webapi` | HTTP API app. |
| 5 | `dotnet new mvc` | MVC web app. |
| 6 | `dotnet new razor` | Razor Pages web app. |
| 7 | `dotnet new blazor` | Blazor web UI app. |
| 8 | `Microsoft.NET.Sdk.Web` | Web project SDK. |
| 9 | `Microsoft.NET.Sdk.Worker` | Worker service SDK. |
| 10 | `Program.cs` | Common app entry point. |
| 11 | `IHost` | Generic hosting abstraction. |
| 12 | `WebApplication` | ASP.NET Core app builder/runtime. |
| 13 | `BackgroundService` | Base class for long-running workers. |
| 14 | `Minimal API` | Lightweight endpoint style. |
| 15 | `Controller API` | Attribute-based Web API style. |
| 16 | `Razor` | Server-side HTML templating. |
| 17 | `Blazor` | Component-based .NET web UI. |
| 18 | `WPF` | Windows desktop UI framework. |
| 19 | `Windows Forms` | Classic Windows desktop UI framework. |
| 20 | `choose by workload` | Match app model to problem shape. |
