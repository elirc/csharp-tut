# .NET From SDK to Production Readiness

A practical .NET platform path in the same paired style as the C#, JavaScript, React, and TypeScript tutorials. Each concept has a lesson file and a matching `*-examples.md` file for repeated practice.

This tutorial assumes you know basic C#. It focuses on the .NET platform around the language: SDKs, CLI, project files, NuGet, configuration, dependency injection, logging, ASP.NET Core, EF Core, testing, publishing, observability, and production habits.

## How to use this

Read a lesson, then work through the matching examples. Type commands by hand, inspect generated files, change project settings, and run small apps. .NET fluency comes from understanding the platform workflow, not just writing C# syntax.

## What "ready to contribute" means here

By the end, you should be able to create and navigate .NET solutions, manage packages, configure apps, use dependency injection and logging, build a small API, test it, publish it, and understand the surrounding production concerns that make .NET work feel professional.
