# 00 - .NET Platform and SDK Examples

| # | Example | Explanation |
|---|---|---|
| 1 | `dotnet --info` | Shows SDK, runtime, OS, and environment information. |
| 2 | `dotnet --version` | Prints the selected SDK version. |
| 3 | `dotnet --list-sdks` | Lists installed SDKs. |
| 4 | `dotnet --list-runtimes` | Lists installed runtimes. |
| 5 | `.NET SDK` | Build tools plus runtime and templates. |
| 6 | `.NET runtime` | Runs already-built applications. |
| 7 | `global.json` | Pins the SDK version for a repo. |
| 8 | `TargetFramework` | Declares the framework an app targets. |
| 9 | `net8.0` | Example target framework moniker. |
| 10 | `Microsoft.NET.Sdk` | Base SDK-style project SDK. |
| 11 | `Microsoft.NET.Sdk.Web` | SDK used by ASP.NET Core projects. |
| 12 | `dotnet new list` | Lists available templates. |
| 13 | `dotnet new console` | Creates a console app. |
| 14 | `dotnet new webapi` | Creates a Web API project. |
| 15 | `dotnet new classlib` | Creates a class library. |
| 16 | `dotnet new xunit` | Creates an xUnit test project. |
| 17 | `bin/` | Build output folder. |
| 18 | `obj/` | Intermediate build and restore files. |
| 19 | `dotnet workload list` | Lists installed optional workloads. |
| 20 | `dotnet sdk check` | Checks SDK and runtime update status. |
