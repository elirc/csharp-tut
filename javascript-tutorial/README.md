# JavaScript From Basics to Real-World Readiness

A practical path from "I can write basic JavaScript" to "I can contribute to real JavaScript projects without being lost." It is designed to mirror the C# tutorial structure: each concept has a main lesson file and a matching examples file.

## How to use this

Read each numbered lesson, then open the matching `*-examples.md` file. Type examples by hand, change them, break them, and rebuild them from memory. JavaScript rewards experimentation, but it also has sharp edges. The examples are there to make the common patterns feel ordinary before you meet them inside a larger app.

## What "ready to contribute" means here

By the end, you should be able to read and write modern JavaScript, reason about async code, work with browser and Node APIs, build a small HTTP API, write tests, understand package tooling, and recognize where TypeScript fits in real teams.
