# 01 - JavaScript Basics Examples

| # | Example | Explanation |
|---|---|---|
| 1 | `console.log("Hello");` | Prints text to the console. |
| 2 | `const name = "Ada";` | Declares a variable that cannot be reassigned. |
| 3 | `let count = 0;` | Declares a variable that can be reassigned. |
| 4 | `count += 1;` | Adds one to the current value. |
| 5 | `count++;` | Increments by one. |
| 6 | `const message = \`Hi, ${name}\`;` | Builds a string with interpolation. |
| 7 | `// comment` | Adds a single-line comment. |
| 8 | `/* comment */` | Adds a block comment. |
| 9 | `const isReady = true;` | Stores a boolean value. |
| 10 | `const total = price + tax;` | Uses arithmetic expressions. |
| 11 | `console.error("Failed");` | Writes to standard error. |
| 12 | `console.table(items);` | Displays tabular data in supported consoles. |
| 13 | `typeof name` | Returns the runtime type label. |
| 14 | `Number("42")` | Converts numeric text to a number. |
| 15 | `String(42)` | Converts a value to text. |
| 16 | `Boolean(1)` | Converts a value to a boolean. |
| 17 | `const x = 1, y = 2;` | Declares multiple constants in one statement. |
| 18 | `let value;` | Declares a variable with value `undefined`. |
| 19 | `"use strict";` | Enables strict mode in scripts that are not modules. |
| 20 | `debugger;` | Pauses execution when dev tools are open. |
