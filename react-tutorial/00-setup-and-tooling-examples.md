# 00 - Setup and Tooling Examples

| # | Example | Explanation |
|---|---|---|
| 1 | `npm create vite@latest app -- --template react` | Creates a Vite React project. |
| 2 | `npm create vite@latest app -- --template react-ts` | Creates a Vite React TypeScript project. |
| 3 | `npm install` | Installs project dependencies. |
| 4 | `npm run dev` | Starts the local dev server. |
| 5 | `npm run build` | Creates a production build. |
| 6 | `npm run preview` | Serves the production build locally. |
| 7 | `src/main.jsx` | React entry file for JavaScript projects. |
| 8 | `src/main.tsx` | React entry file for TypeScript projects. |
| 9 | `createRoot(root).render(<App />)` | Mounts React into the page. |
| 10 | `StrictMode` | Helps surface development-only issues. |
| 11 | `App.jsx` | Common starter component file. |
| 12 | `index.html` | HTML page shell used by Vite. |
| 13 | `package.json` | Stores scripts and dependencies. |
| 14 | `vite.config.js` | Optional Vite configuration file. |
| 15 | `npm install react-router-dom` | Adds routing support. |
| 16 | `npm install -D vitest` | Adds a test runner. |
| 17 | `npm install -D @testing-library/react` | Adds React testing helpers. |
| 18 | `npm install -D eslint` | Adds linting support. |
| 19 | `React Developer Tools` | Browser extension for inspecting components. |
| 20 | `node_modules/` | Generated dependency folder that should not be committed. |
