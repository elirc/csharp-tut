# React From Components to Real-World Readiness

A practical React path in the same paired style as the C# and JavaScript tutorials. Each concept has a lesson file and a matching `*-examples.md` file for repeated practice.

This tutorial assumes you know enough JavaScript to write functions, arrays, objects, modules, and async code. React is not a replacement for JavaScript; it is a UI library built on top of it.

## How to use this

Read a lesson, then work through the matching examples. Type examples by hand, change props, move state, break effects, and rebuild small components from memory. React skill comes from understanding data flow and component boundaries, not memorizing every API.

## What "ready to contribute" means here

By the end, you should be able to build a small React app with components, props, state, forms, effects, routing, tests, API integration, and a clear sense of when local state, lifted state, context, reducers, or server-state tools are appropriate.
