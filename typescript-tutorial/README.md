# TypeScript From Types to Real-World Readiness

A practical TypeScript path in the same paired style as the C#, JavaScript, and React tutorials. Each concept has a lesson file and a matching `*-examples.md` file for repeated practice.

This tutorial assumes you already know basic JavaScript. TypeScript does not replace JavaScript; it adds a static type system on top of JavaScript so you can catch mistakes earlier, document intent, and refactor with more confidence.

## How to use this

Read a lesson, then work through the matching examples. Type examples by hand, change them, and intentionally create type errors. TypeScript is learned by watching what the compiler accepts, rejects, narrows, and infers.

## What "ready to contribute" means here

By the end, you should be able to read and write typed JavaScript, model data with types and interfaces, narrow unions safely, write generic helpers, configure strict projects, work across API boundaries, and understand when TypeScript helps versus when runtime validation is still required.
