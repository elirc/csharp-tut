# Node.js From Runtime to Backend Readiness

A practical Node.js path in the same paired style as the C#, JavaScript, React, TypeScript, and .NET tutorials. Each concept has a lesson file and a matching `*-examples.md` file for repeated practice.

This tutorial assumes you know basic JavaScript. It focuses on Node.js as a runtime for scripts, CLIs, backend services, APIs, workers, and tooling.

## How to use this

Read a lesson, then work through the matching examples. Type commands and snippets by hand, run them in Node, inspect errors, and build small services. Node skill comes from understanding the runtime, the module/package system, async I/O, streams, HTTP, testing, and production behavior.

## What "ready to contribute" means here

By the end, you should be able to create Node projects, manage packages, write modules, build scripts and APIs, handle async I/O, test behavior, validate inputs, manage configuration, and understand the operational concerns of running Node services.
